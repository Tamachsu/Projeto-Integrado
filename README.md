## Proposta de Tecnologias a Estudar de forma autónoma 

O objetivo é completar a formação básica em sala de aula com novos conhecimentos alinhados com o perfil de estágio.  

A aprendizagem tem de ser certificada com a apresentação de certificados de conclusão dos cursos online escolhidos. Algumas  plataformas com cursos online: 

O site freeCodeCamp tem cursos gratuitos com certificação 

Coursera, Udemy, Edx, Udacity são plataformas com cursos online a maior parte pagos 

 
- [Introdução ao Java e Orientação a objetos](https://www.udemy.com/cart/subscribe/course/2149066/)

- [Configurando o ambiente de desenvolvimento em Java](https://www.udemy.com/cart/subscribe/course/2149066/)
